<h3 id="anchorctl">AnchorCTL</h3>

Options:

* **`--type`** Command-line utility
* **`--status`** Under development
* **`--focus`** Distributed systems testing
* **`--repository`** [github.com/covarity/anchorctl](https://github.com/covarity/anchorctl)
* **`--example`** [OPA admission-controller testing](https://github.com/covarity/examples/tree/master/examples/test-admission-controller)
* **`--presentation`** [Conference talks](https://github.com/covarity/conference-talks)

Anchorctl is a command line utility that enables a test driven approach to developing distributed systems like Kubernetes. The utility works in conjunction with Anchor kubernetes controller (Under development) to create a CRD based user experience for testing systems.
